# Credit Scoring ML Pipeline 

 пайплайн кредитного скоринга для оценки вероятности дефолта заёмщика. Проект трансформирован из исследовательского ноутбука в модульный Python-пакет с базами данных, автоматической подготовкой признаков и SHAP-интерпретируемостью.

## Технологический стек
* **Python 3.14**
* **SQLite 3 & SQL** — хранение сырых данных и витрин признаков
* **CatBoost** — бинарная классификация (градиентный бустинг)
* **SHAP & Matplotlib** — интерпретируемость предсказаний модели и визуализация
* **Pathlib & Pandas** — обработка данных и управление путями

# Структура проекта
```text
credit-scoring-pipeline/
├── data/                  # Хранилище SQLite БД (.gitkeep)
├── models/                # Сохранённые артефакты моделей (.cbm)
├── reports/figures/       # Визуализации (ROC-AUC, SHAP plots)
├── scripts/               # Скрипты инициализации (init_db.py)
├── sql/                   # SQL-запросы для Feature Engineering
├── src/                   # Модульный код пайплайна
│   ├── __init__.py
│   ├── config.py          # Конфигурация путей и параметров
│   ├── data.py            # Извлечение из SQL и препроцессинг
│   ├── train.py           # Обучение CatBoost с Early Stopping
│   └── evaluate.py        # Метрики оценки и SHAP-анализ
└── main.py                # Единая точка входа в пайплайн
